## 🚀 What is Angularize?

**Angularize.dev** is an AI-powered platform that generates complete, production-ready **Angular applications** from natural language prompts — instantly. Think of it like [Lovable](https://lovable.dev), but purpose-built for the **Angular ecosystem**.

You type a prompt. We generate a full Angular app — components, services, routing, modules, and clean TypeScript code — ready to run.

> Built by **Madhan Mohan** ([@Madhan-mohan14](https://github.com/Madhan-mohan14)) and **Mahbob**.

---

## 🧠 How It Works — Multi-Agent Architecture

Angularize is not a single AI call. It is powered by a **custom multi-agent system** where specialized agents collaborate to produce a full Angular project.

The **Orchestrator Agent** receives the user prompt, understands intent, and breaks the task into subtasks. It coordinates three specialist agents:

- **Component Agent** — Generates Angular components, HTML templates, and styles
- **Service & Data Agent** — Creates services, HTTP calls, and state management
- **Routing & Module Agent** — Wires everything together into `app.module.ts` and the router config

The final output is a complete, runnable Angular project delivered as a GitHub repo and a live preview.

- **Complete Project Output** — Full `src/` folder with modules, components, services, routing, and styles

- **TypeScript Native** — All generated code is strongly typed

Every one of them is a **test Angular project generated by the Angularize platform** during development and QA.
